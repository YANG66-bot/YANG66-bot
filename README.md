## Engineering Focus

- **Architecture first:** define boundaries and communication paths before optimizing implementation details.
- **Clarity over cleverness:** prefer explicit interfaces, readable code, and designs that are easy to maintain.
- **Performance with purpose:** improve latency, resource use, and reliability where they create real product value.
